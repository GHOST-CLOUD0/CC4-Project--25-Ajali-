# Ajali!

Ajali! is a localized emergency and incident-reporting platform.

## Repository layout

- `backend/` is reserved for the Flask API and PostgreSQL integration.
- `frontend/` is reserved for the React and Redux Toolkit application.
- `docs/` contains project design, API, wireframe, and tracker documents.

## Current stage

This repository contains structure and documentation only. Source files, tests, configuration files, and environment templates are intentionally empty until implementation begins.
